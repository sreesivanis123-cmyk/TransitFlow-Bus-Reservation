TRANSITFLOW – Bus Reservation & Fleet Scheduling System
========================================================
Open index.html in any modern browser.

Included:
- Dashboard
- Booking management with working "New Booking" interaction
- Fleet & buses
- Schedules
- Passengers
- Routes
- Responsive layout
- No external libraries or internet connection required

For your DBMS submission:
This is the front-end demonstration. The database can be connected later using PHP/MySQL (XAMPP) by replacing the sample JavaScript data/actions with server-side API calls.
